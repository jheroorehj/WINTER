설계 프로토타입 모델 미연결 레이아웃 확인용 배포

아래 화면은 컴포넌트 배치와 인터랙션을 확인하기 위한 디자인 프로토타입입니다. 표시되는 수치는 전부 시연용 목업이며, 학습된 모델이 낸 값이 아닙니다.

프로토타입 열기 GitHub
표시되는 안저 영상은 샘플입니다. 공개 데이터셋에서 8장을 가져와 화면 확인용으로 쓰고 있으며, 화면의 소견·유사도 수치와는 관계가 없습니다. 목업 환자 3명이 같은 8장을 공유하므로 케이스를 전환해도 사진은 바뀌지 않습니다.
프로토타입은 16:9 고정 캔버스(설계 기준 1920×1080)로, 브라우저 가로 폭에 맞춰 전체가 확대·축소됩니다. 데스크톱 해상도에서는 비율이 유지된 채로 화면을 꽉 채웁니다. 창이 1152px보다 좁아지면 글자가 읽기 어려워지므로 더 줄이지 않고 가로 스크롤이 생깁니다. React와 컴파일러를 실행 시점에 CDN에서 받아오므로 첫 로딩이 몇 초 걸릴 수 있습니다.
이 도구는 진단 기기가 아닙니다. 화면의 값은 통계적 추정치이며 확진이 아니고, 최종 판단은 의료진의 임상 소견에 따릅니다. 목업 환자는 시연용 가상 인물이며 실제 환자가 아닙니다.
