# 샘플 안저 영상

프로토타입 화면 확인용 샘플 8장입니다. **시연·레이아웃 확인 목적이며, 화면에 표시되는
소견·유사도 수치와는 아무 관계가 없습니다.** 모델이 이 영상을 보고 낸 결과가 아닙니다.

## 파일

| 파일 | 화면상 역할 |
| --- | --- |
| `patient-os.jpg` | 3번 패널 — 현재 환자 좌안 (OS) |
| `patient-od.jpg` | 4번 패널 — 현재 환자 우안 (OD) |
| `similar-os-1.jpg` · `-2` · `-3` | 5-7번 카드 — 좌안 유사 사례 |
| `similar-od-1.jpg` · `-2` · `-3` | 8-10번 카드 — 우안 유사 사례 |

512×512 RGB JPEG. 환자 3명(목업)이 같은 8장을 공유하므로, 데모 케이스를 전환해도
사진은 바뀌지 않습니다. 경로는 `망막분석 EMR.dc.html` 의 `DEMO_IMG` 한 곳에만 정의돼 있습니다.

## 출처

공개 안저 데이터셋(`archive/` — ODIR-5K 계열)의 전처리본에서 8장을 골라 복사했습니다.
원본 파일명은 데이터셋 레코드 식별자였으므로, 화면상 역할이 드러나는 이름으로 바꿨습니다.
EXIF·ICC 프로파일은 원본에 없었고 추가하지 않았습니다.

모두 시연용 가상 데이터입니다.
